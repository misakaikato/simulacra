# 2026-09-02 同时建设模拟内核与稳健性审计 harness，并开源

- 选了：内核（simulacra）+ harness 一起做，harness 作为内核的第一个消费者，也能通过 run 契约审计外部模拟。
- 没选：只做 harness 薄层（2026-09-02 上午的推荐）。用户在听取"通用底层库位置已被 OASIS / AgentSociety 2 / Concordia 占住"的分析后仍决定两者都做，理由是要一个扩展性更高、吸收各家优缺点的版本。
- 判据（沿用上午的权重）：空隙真实性 5 / 单人可交付 5 / 采用路径 3 / 商业选项 3 / 可逆性 2。
- 两者都做的代价：可交付性判据从 4 降到 2 到 3；对冲是分阶段交付，A 阶段内核最小闭环、B 阶段 harness、C 阶段规模化执行体，每阶段单独可停。
- 差异化立场（内核不做第 N 个通用框架的理由）：
  1. 类型化状态总线做唯一真相，动作与效果是数据，世界状态不再是自由文本或散落的 SQL。
  2. 事件溯源 + LLM 网关录制回放，同配置同种子可逐字节复现，真实 LLM 的非确定性被隔离在录制层。
  3. 决策提供者是批级协议，LLM / 代理 / 原型 / 缓存 / 规则同一人口混跑，来源与成本逐决策记账。
  4. 实验设计（假设 / 对照臂 / 结果）进核心，审计 harness 是内核的一等消费者而非事后脚本。
  5. 失败是一等输出，完整性断言在 run 结束时执行。
- 关键假设与信心：
  - 现有框架的痛点（改核心才能扩展、时间不可复现、失败被吞、字符串协议）确实是研究者的采用障碍，而不只是工程洁癖（信心中，证据是四家 issue 区的重复投诉）。
  - 单人能在 A 阶段（约 4 周）交付一个可跑的最小闭环（信心中低，预死亡第一名）。
- 预死亡前三名与对冲：
  1. 内核做大后 harness 迟迟不出，失去差异化。对冲：B 阶段 harness 对外部模拟（OASIS 适配器）先可用，不等内核完善。
  2. 抽象过多，用户学不会。对冲：六个协议以外一律插件；示例只用声明式 YAML + 一个 Python 文件。
  3. 与 OASIS / Concordia 社区零交集。对冲：适配器与事件日志导入器让它们的用户零迁移即可审计。
- 复盘点：A 阶段结束（预计 2026-10 上旬）看两个示例是否在 MockLLM 下逐字节可复现；B 阶段结束看 OASIS 用户能否用适配器跑出审计报告。
- 规格（初版，Python，已作废）：见下方修订。

## 2026-09-02 晚 修订：用户指令扩展范围并改语言

- 语言改为 TypeScript（Bun 运行时），充分使用类型系统与函数式风格；Python 版规格作废删除，避免第二真相源。
- 范围新增：完善 CLI、可视化 GUI、MCP 服务、HTTP API、结构化日志；性能测试用 piagent 配置的 DeepSeek（严格限额）；git 管理不署名 AI；README 带 codex 生成的 banner；开源上传到 GitHub。

- npm 名 `simulacra` 已被占用，包名定为 `@misakaikato/simulacra`，bin 仍为 `simulacra`；仓库名 `simulacra`。

## 2026-09-03 交付结果

- 仓库公开：https://github.com/misakaikato/simulacra（Apache-2.0，单一作者，无 AI 署名）。
- 五个阶段全部交付并通过独立验收：A 内核（三段，各打回一轮）、B harness 与适配器（零打回）、C 规模化执行体与降本提供者（零打回）、D API/MCP/GUI（打回一轮）、E 性能脚本与真实模型测试。
- 门禁：388 个测试全绿、类型检查与 lint 与格式检查通过、GUI 构建通过。
- 性能：1k focal × 20 tick 5.6 s；100k cohort × 20 tick 25.8 s；DeepSeek 真实模型两示例 38 次调用（预算 150），0 解析失败。
- 真实模型暴露的缺口与修复：DeepSeek v4-flash 的推理内容占满 max_tokens 使答案为空；加入 `LLMSpec.extra` 透传厂商参数、预设默认关思考、`finish_reason` 记录与 `truncated`/`empty_content` 失败类型。
- 已知局限（写在 README）：resume 跳过检查点之后的干预与问卷步骤；APS 默认参数面向 N ≥ 5000。
- 复盘要点：并行施工用 worktree 隔离有效，唯一冲突是 `src/index.ts` 导出列表；每阶段的裁定即时写入规格附录避免了合同漂移；验收分身独立于施工分身，五次验收发现的缺陷全部是真缺陷（溢出回绕、失败被吞、分层违反、SSE 断流）。
